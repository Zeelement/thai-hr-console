## 根因确诊与打通：SQL Server TCP/IP 未启用 → 改 Shared Memory（17:14）

用户贴 `10061 积极拒绝`。做只读诊断（未启停任何进程）确认：SQL Server 2025 默认实例 MSSQLSERVER 服务运行中、sqlservr PID 在跑，但 1433 无监听；注册表 `SuperSocketNetLib\Tcp\Enabled=0`（TCP/IP 禁用），只开了 Shared Memory（`Sm\Enabled=1`）；sqlservr 仅监听 1434（DAC）。故 10061 根因是 **TCP/IP 协议禁用**，与密码/库无关。

修复（无需启停服务、无需改系统配置）：用 pyodbc 只读测试连接串，确认 `SERVER=localhost`（无端口）、`SERVER=lpc:localhost` 均可连上（返回 SQL Server 2025 版本），`SERVER=localhost,1433` 失败。据此改动：
- `config/settings.py`：`_mssql_config()` 增加 `HR_DB_LOCAL=1` 分支 —— HOST 用 `lpc:localhost`、PORT 置空，使 mssql-django 不拼端口、走 Shared Memory。`HR_DB_LOCAL=0` 仍走 TCP。
- `start.bat`：默认 `HR_DB_LOCAL=1`，打印 Mode（LOCAL/TCP），顶部注释说明切换方式。
- `README.md`：更新连接说明与切换示例。
